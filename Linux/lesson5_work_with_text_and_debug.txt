1. grep — поиск по шаблону

	grep "error" file.txt
	grep -i "error" file.txt          # игнор регистра
	grep -r "TODO" ./project           # рекурсивно по папке
	grep -n "error" file.txt           # с номером строки
	grep -v "debug" file.txt           # инвертировать — БЕЗ совпадений
	grep -c "error" file.txt           # только количество
	grep -A 3 "error" file.txt         # -A (after) — показать 3 строки ПОСЛЕ совпадения
	grep -B 3 "error" file.txt         # -B (before) — 3 строки ДО совпадения
	
2. cut — вырезать колонки

Работает построчно, разбивая строку по разделителю и вытаскивая нужные "столбцы".

	cut -d':' -f1 /etc/passwd          # -d — разделитель ":", -f1 — первое поле
	echo "a,b,c,d" | cut -d',' -f2,4    # несколько полей: 2-е и 4-е
	echo "a,b,c,d" | cut -d',' -f2-4    # диапазон: со 2-го по 4-й

/etc/passwd разделён двоеточиями, cut -d':' -f1 вытащит только имена пользователей из файла.

cut хорош, когда данные строго структурированы по одному разделителю. Если разделители "плавающие" (разное число пробелов) — лучше awk.


3. sort — сортировка строк

	sort file.txt              # по алфавиту
	sort -r file.txt             # -r — в обратном порядке
	sort -n file.txt             # -n — числовая сортировка (иначе "10" встанет перед "2")
	sort -k2 file.txt             # -k2 — сортировать по 2-й колонке
	sort -u file.txt              # -u — сразу убрать дубликаты после сортировки

Oшибкa сортировать числа без -n — тогда sort сравнивает их как текст, и получаешь 1, 10, 2, 20, 3 вместо нормального порядка.

4. uniq — убрать повторяющиеся строки

uniq убирает только соседние одинаковые строки, поэтому почти всегда используется в связке с sort перед ним:

	sort file.txt | uniq

Полезные флаги:

	sort file.txt | uniq -c        # -c — посчитать, сколько раз встретилась каждая строка
	sort file.txt | uniq -d        # -d — показать ТОЛЬКО те, что повторялись

Классический паттерн для анализа логов — топ повторяющихся IP-адресов:

	cat access.log | awk '{print $1}' | sort | uniq -c | sort -rn | head

5. wc — подсчёт

	wc file.txt          # строки, слова, байты — сразу все три числа
	wc -l file.txt         # только количество строк
	wc -w file.txt          # только количество слов
	wc -c file.txt           # только количество байт

6. sed — потоковый редактор (замена текста)

sed (stream editor) читает текст построчно и применяет к нему операции — чаще всего замену.

	sed 's/old/new/' file.txt          # заменить ПЕРВОЕ вхождение "old" на "new" в каждой строке
	sed 's/old/new/g' file.txt          # -g (global) — заменить ВСЕ вхождения в строке
	sed -i 's/old/new/g' file.txt        # -i (in-place) — изменить сам файл, а не просто вывести на экран
	sed -n '5,10p' file.txt              # -n + p — вывести только строки с 5 по 10
	sed '/pattern/d' file.txt             # d — удалить строки, содержащие pattern

Синтаксис s/старое/новое/g — это конструкция замены: s = substitute, слэши разделяют части, g = global (все вхождения, не только первое в строке).

Осторожно с -i — он меняет файл сразу и без подтверждения. 
Хорошая практика перед массовыми правками: сделать бэкап sed -i.bak 's/.../.../ ' file.txt — тогда исходник сохранится как file.txt.bak.

Пример из практики: массово поменять IP-адрес во всех конфигах:
	
	sed -i 's/192.168.1.1/192.168.1.2/g' /etc/nginx/nginx.conf

7. awk — самый мощный инструмент из этого списка

awk — это по сути мини-язык программирования для построчной обработки текста, ориентированный на колонки. 
По умолчанию делит каждую строку на поля по пробелам/табам, и обращается к ним как $1, $2, $3... а $0 — вся строка целиком.

	echo "user1 25 Moscow" | awk '{print $1}'          # выведет: user1
	echo "user1 25 Moscow" | awk '{print $2, $3}'       # выведет: 25 Moscow
	awk -F':' '{print $1}' /etc/passwd                  # -F — свой разделитель (двоеточие вместо пробела)

Фильтрация по условию:

	awk '$3 > 100 {print $1}' data.txt        # вывести первую колонку, где 3-я колонка > 100
	awk '/error/ {print}' log.txt              # то же самое, что grep, но через awk

Встроенные переменные, которые часто нужны:
	
	awk '{print NR, $0}' file.txt      # NR — номер текущей строки
	awk '{print NF}' file.txt           # NF — количество полей в строке

8. xargs — передать вывод как аргументы

Разница с пайпом |:

	| передаёт вывод одной команды на stdin следующей Но не всякая команда читает stdin — многим (например, rm, cp) нужны аргументы командной строки, а не поток на входе

xargs решает эту проблему — превращает то, что пришло по пайпу, в аргументы для следующей команды.

	find . -name "*.tmp" | xargs rm          # найти .tmp файлы и передать их именно как аргументы в rm
	echo "file1.txt file2.txt" | xargs cat    # превратить строку в аргументы для cat

Без xargs команда find . -name "*.tmp" | rm вообще не сработает — rm не читает список файлов из stdin, ему нужны имена файлов как аргументы после команды.
Полезный флаг для безопасности с именами с пробелами:

	find . -name "*.tmp" -print0 | xargs -0 rm

-print0/-0 разделяют имена файлов нулевым байтом вместо пробела — защита от файлов с пробелами в имени, которые иначе сломают команду.

Собираем всё вместе — разбор однострочника

	cat access.log | awk '{print $1}' | sort | uniq -c | sort -rn | head

1) cat access.log — читаем лог
2) awk '{print $1}' — берём первую колонку (обычно это IP-адрес в логах веб-сервера)
3) sort — сортируем (нужно перед uniq, иначе он не сработает правильно)
4) uniq -c — считаем, сколько раз встретился каждый уникальный IP
5) sort -rn — сортируем по числу (count), по убыванию
6) head — показываем только топ-10

Результат: топ-10 IP-адресов по количеству запросов в логе
