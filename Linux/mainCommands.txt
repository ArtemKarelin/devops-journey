Базовые команды

1. cd (change directory)
	cd /home/user   #абсолютный путь от корня
	cd Dokuments	#относительный путь от текущей позиции
	cd . .		#поднятся на уровень выше
	cd ~		#перейти в домашнюю папку
	cd -		#вернуться в предыдущую папку
Абсолютный путь начинается с "/" и работает откуда угодно. Относительный зависит от того где ты сейчас находишься. (Узнать можно с командой pwd)

2. mkdir (make directory)
	mkdir project
	mkdir -p project/user/info	#создаст сразу цепочку файлов 
Без флага -p mkdir откажется создавать новую папку если родительская не существует

3. touch (Создает пустой файл или обновляет время изменения, если файл уже есть)
	touch main.c

4. rm / rm -rf (удаление)
	rm file.txt	#удалить файл
	rm -r		#-r(recursive) удалить папку со всем содержимым
	rm -rf		#-rf (force) безвозвратно, и без вопросов




5. chmod (change mode) меняет права доступа к файлу

Пример	
drwxrwxr-x  2 burmalda burmalda 4096 июл 31 11:20 Linux/

Первая буква d - это обозначение директории. Так же может быть прочерк что означает обычный файл

rwxrwxr-x — права (9 символов, три группы по три)

Что означают r, w, x на самом деле

Для файла:

r — можешь прочитать содержимое (cat, открыть в редакторе)
w — можешь изменить/перезаписать содержимое
x — можешь выполнить файл как программу/скрипт

Для директории (это часто путает новичков):

r — можешь посмотреть список файлов внутри (ls)
w — можешь создавать/удалять файлы внутри
x — можешь зайти в директорию (cd) и обращаться к файлам внутри по имени

Разобьём на три блока по три буквы:
rwx | rwx | r-x
 u  |  g  |  o
u - владелец(burmalda) может все
g - группа владельцев (тоже burmalda) может все
о - others все остальные пользователи системы. Немогут ничего создавать/удалять внутри

Числовая запись (octal)

Каждое право — это бит, у бит есть вес:

r = 4
w = 2
x = 1

Складываешь то, что нужно, для каждой из трёх категорий (owner, group, others):

bash
chmod 750 script.sh
7 = 4+2+1 = rwx → владелец: всё
5 = 4+0+1 = r-x → группа: читать и выполнять
0 = 0 → остальные: ничего

Самые частые значения, которые реально стоит запомнить наизусть:

Число	Права	Где используется
600	rw-------	приватные файлы, SSH-ключи (id_rsa)
644	rw-r--r--	обычные файлы, конфиги для чтения
700	rwx------	приватные скрипты/папки
755	rwxr-xr-x	исполняемые скрипты, публичные директории
777	rwxrwxrwx	всем можно всё — почти всегда плохая идея
Символьная запись

Иногда удобнее не считать числа, а просто добавить/убрать конкретное право:

bash
chmod +x script.sh        # добавить выполнение всем
chmod u+x script.sh       # добавить выполнение только владельцу (u = user)
chmod g-w file.txt        # забрать право записи у группы
chmod o=r file.txt        # у "остальных" выставить ровно "только чтение"
chmod a+r file.txt        # a = all (owner+group+others)

Буквы: u (user/owner), g (group), o (others), a (all). Операторы: + добавить, - убрать, = выставить ровно так.

Это удобно, когда нужно поменять одно право, не трогая остальные — не надо пересчитывать всю восьмеричную комбинацию заново.

Рекурсивно
bash
chmod -R 755 project/

-R применит права ко всем файлам и папкам внутри.
 Осторожно: часто права для файлов и директорий должны отличаться (папкам нужен x для входа, файлам — не всегда),
 поэтому массовый -R 777 на весь проект — плохая практика, лучше отдельно задать права для папок и файлов.
