7. ls (Навигация и просмотр)

	ls		#список фалов в текущей папке
	ls -l		#длинный формат (права, владелец, размер, дата) - то что было в chmod
	ls -a		#показать скрытые файлы начинающиеся с точки (например .minecraft)
	ls -la		#комбинация: длинный формат + скрытые файлы
	ls -lh		#-h (human-readable) - размеры в KB/MB/GB а не в байтах
	ls -lt		#сортировка по времени изменения (новые сверху)
8. cat (concatenate)
	cat file.txt				# вывести содержимое файла целиком на экран
	cat file1.txt file2.txt			# вывести оба файла подряд
	cat -n file.txt				# с номерами строк
	cat file1.txt file2.txt > merged.txt	# склеить файлы в один
Проблема cat: если файл очень длинный, всё улетит в терминал разом — для решения этого есть less.

9. less 
	less file.txt		#Открывает файл постранично, можно листать.

	Управление:
	Space / f   — вперёд на страницу
	b           — назад
	/слово      — поиск по тексту,
	n           — следующее совпадение
	q           — выйти

10. tail
	tail file.txt            # последние 10 строк файла
	tail -n 20 file.txt      # последние 20 строк
	tail -f /var/log/syslog  # -f (follow) — "живой" просмотр, новые строки появляются в реальном времени
	
tail -f — одна из самых используемых команд в DevOps вообще, потому что именно так смотрят логи приложения в реальном времени, пока оно работает.

Есть парная команда head — то же самое, но с начала файла:
	head -n 20 file.txt

11. grep (global regular expression print) ищет текст внутри файла по шаблону
	grep "error" logfile.txt          # найти строки со словом "error"
	grep -i "error" logfile.txt        # -i — игнорировать регистр
	grep -r "TODO" ./project           # -r — рекурсивно по всем файлам в папке
	grep -n "error" logfile.txt        # -n — показать номер строки
	grep -v "debug" logfile.txt        # -v — инвертировать: показать строки БЕЗ "debug"
	grep -c "error" logfile.txt        # -c — просто посчитать количество совпадений
grep понимает регулярные выражения, это отдельная большая тема, но даже без regex это уже мощнейший инструмент.
Пример реального юз-кейса: grep -i "failed" /var/log/auth.log — найти попытки неудачного логина на сервере.

Работа с файлами

12. cp (copy)
	cp file.txt backup.txt          # скопировать файл
	cp file.txt /home/user/docs/     # скопировать в другую папку
	cp -r folder1 folder2            # -r — скопировать папку рекурсивно (обязательно для папок!)
	cp -v file.txt backup.txt        # -v (verbose) — показать, что происходит
Без -r копирование папки выдаст ошибку — так же, как с rm.

13. mv (move)
	mv file.txt /home/user/docs/      # переместить файл
	mv oldname.txt newname.txt         # переименовать (в Linux нет отдельной команды "rename" — это тот же mv)
